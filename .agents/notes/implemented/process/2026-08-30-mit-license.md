# Agent Note: 问爻原创源代码采用 MIT 许可

Status: implemented

## Problem

公开仓库只有可见源码而没有明确许可证时，外部使用者缺少复制、修改和再分发代码的法律许可，项目也不能准确宣称为开源软件。

## Decision

问爻原创源代码使用 MIT License 发布，版权主体标识为 `ROTl24`。分发副本或实质性代码时必须保留版权与许可声明，软件按现状提供且不承担担保责任。第三方依赖、字体、古籍和数据继续受各自许可及来源说明约束。

## Alternatives considered

- 仅公开源码但不附许可证：该方式不能向使用者授予明确的使用、修改和分发权，不满足开源发布目标。
- GPL 或 AGPL：强制衍生版本继续开源，与当前允许广泛复用和再分发的目标不一致。
- Apache-2.0：提供更明确的专利授权与终止条款，但当前项目没有需要额外专利条款解决的已知约束，MIT 的简洁许可足以满足发布目标。

## Consequences

- 外部使用者可在保留版权与许可声明的前提下使用、复制、修改、合并、发布、分发、再许可或销售问爻原创代码。
- 项目可以准确使用“免费开源”描述，但该描述不代表第三方 AI 服务免费，也不改变第三方素材和依赖的许可。
- 若未来版权主体、贡献者协议或第三方资产边界发生变化，必须重新检查 LICENSE、NOTICE 与 README 的一致性。

## Verification

- 根目录存在标准 MIT `LICENSE`。
- `package.json` 与 `package-lock.json` 的根包元数据声明 `MIT`。
- README 链接许可证并明确第三方许可边界。
