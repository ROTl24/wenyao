# Agent Note: 生成任务保留可读正文与独立未完成草稿

Status: implemented

## Problem

长解读只有阶段提示时，用户不能提前阅读正文；切换页面会失去等待状态。服务中断、用户停止或输出额度耗尽时，已经出现的文字也不能证明报告完整。重新生成后的草稿和上一份报告可能使用不同证据，来源混用会影响核对。

## Decision

桌面内置 SSE 服务和 PWA 的生成、追问向界面传递最终正文片段与阶段，内部推理仅作为阶段信号。进度在内存中累计，每 200 毫秒合并界面更新；正文以安全 Markdown 排版，禁止草稿加载外部图片。既有完整 Markdown 组件按内容记忆，减少追问流期间的重复解析。流式 Markdown 按完整顶层块缓存，只继续解析末尾两个可变块，保留表格、列表、代码围栏及跨片段语法；遇到引用或脚注定义时按整篇解析，保证后置定义仍能影响前文。

原文块保留源字符偏移。界面更新前记录可见草稿段落的位置，更新后在结果页实际滚动容器中恢复；最终报告插入结论速览也保留当前段落。只对可见草稿生效，不把正在查看排盘、依据或另一记录的用户拉回正文。

任务按会话及请求标识管理，状态覆盖生成、停止中、保存、完成、失败、已停止和保存失败。切换应用内页面后请求继续，任务入口保留完成与失败通知；同一会话在生成或保存期间不发起另一生成。首次解读完成后才能对其结果继续追问。页面锁继续限制 PWA 的并发计费请求。

Electron 的中断按渲染进程归属和请求标识定位；Worker 使用同一请求生命周期入口。取消会触发 AbortSignal；被接受的停止不能被迟到成功逆转。PWA 等待页面锁时的停止会阻止请求发出。检索阶段停止后等待当前检索收尾，不再启动生成；所有路径均不自动重发。

完整响应通过既有解析后才写入正式报告或助手回答。服务商以输出额度结束时，即便已经返回正文也按未完成处理。停止或失败保存为 `generationDraft`，保留问题、正文、状态、时间及本次证据快照，不进入正式报告、助手回答或质量评分。草稿引用使用独立定位目标，保留上一份完整报告的依据。成功生成清空旧草稿；写入失败保留内存结果，重试只保存，不请求模型。

## Alternatives considered

- 每次追加重排整篇 Markdown 会重复处理已稳定的段落；仅按空行切块又会破坏列表、表格、围栏和后置引用定义。
- 每个片段写入正式报告会把未完成内容伪装成成功，并增加本机存储写入。
- 仅隐藏等待界面不能中断连接，也不能防止迟到结果覆盖停止状态。
- 自动续写或重发无法判断服务商是否已经计费，与单次调用边界不符。
- 强制自定义 JSON 服务切换 SSE 会改变现有接口协议；其正文仍在收到完整 JSON 响应后呈现，停止入口可中断连接。
- 为应用退出后的任务建立常驻服务与远程任务恢复，需要服务商提供可验证的任务状态及取消契约。

## Consequences

用户可以在应用内切页并返回阅读，完成报告与未完成草稿具有不同保存语义。任务运行状态只存在于当前应用会话；关闭或刷新会中断接收，未提交的片段不保证保留。停止本机接收不能证明服务商停止处理或计费。需要退出后恢复或多实例共享任务时重新评估生命周期边界。

## Verification

- Provider 测试覆盖正文提前到达、内部推理不外传、输出额度截断不成功及单次请求；既有活跃流、空闲超时与完成后清理回归继续通过。
- 共享请求测试覆盖渲染进程归属、重复请求、销毁、真实 AbortSignal 和迟到成功拒绝；preload、Web Client 与 Worker 测试覆盖事件路由、早停、清理及传输中断。
- App 回归覆盖切页返回、检索阶段停止、草稿保存、迟到结果拒绝、同会话顺序和本机保存重试；备份往返保留草稿及快照，拒绝伪造的完成状态。
- 本地浏览器在 1280×800 和 390×844 使用合成报告验收正文阅读、草稿引用、后台完成与追问停止；未发现横向溢出或控制台错误。未调用真实模型，未验证服务商取消计费，未发布安装包。

- 长文专项：真实本机 HTTP SSE 传输超过 6 万字符，分割 UTF-8、JSON 与事件边界，验证响应结束前可读、最终逐字一致、真实连接中止且不重试。
- 1280×800 与 390×844 的真实 Web Provider + App 合成长文验收使用 68,108 字符。首次正文分别约 241/249ms，生成期间 App 渲染 P95 约 20/30ms；这些是当前机器开发模式下的合成样例观察，不是服务商时延或性能保证。手机从 60,000 字符追加到全文时，同一段落位置不变；两种尺寸完成切换的段落偏移均小于 1px。完整保存逐字一致，无横向溢出或控制台错误。
- 新增跨片段 Markdown 等价、6 万字符缓存复用及滚动容器回归；合计 306 项 Renderer、165 项 Electron 测试通过，类型、构建和 PWA 产物校验通过。
